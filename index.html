One-time Photoshop setup
  1. Restart Photoshop after installing Icon Fast Fit.
  2. Open Edit → Keyboard Shortcuts.
  3. Select Application Menus.
  4. Expand File → Scripts → Icon Fast Fit.
  5. Click the shortcut field, press your preferred combination, then save the shortcut set.
Photoshop assigns the shortcut to the installed script command. It remains available when this panel is closed or unfocused.
