GLOBAL PHOTOSHOP SHORTCUT

Icon Fast Fit.jsx is installed into each detected Photoshop Presets\Scripts folder by Install-Windows.bat.
After restarting Photoshop, it appears under File > Scripts > Icon Fast Fit.
Assign a global-in-Photoshop shortcut through Edit > Keyboard Shortcuts > Application Menus > File > Scripts.
The script reads the settings saved by the CEP panel and invokes the same host operation.
